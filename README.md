## Turn Pages on — one time, on your phone

I cannot flip this switch from here. You can in 20 seconds:

1. Open https://github.com/Tamangkapa-cpu/PROJECTR/settings/pages
2. **Build and deployment → Source**
3. Choose **GitHub Actions**  
   or **Deploy from a branch** → `main` → `/web` → Save
4. Wait about a minute, then open the live link above

## Run locally

```bash
cd web
python3 -m http.server 8080
```
