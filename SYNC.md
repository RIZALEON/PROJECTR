- The Meta page is the source of truth. GitHub Pages mirrors it.
- Every site links every other site in this file. If a link ever changes,
  update `SYNC.md` and `SHARED-SPACE.md` in the same push and append a
  HANDOFFS entry (BACKROOM.md protocol).

  bot that changes one site checks this file, updates every other seat it
  can reach, and logs in `HANDOFFS.md` what it could not reach.
