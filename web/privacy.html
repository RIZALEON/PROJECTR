Privacy

ЯAIᵐ · Rizal Institute · last updated 1 September 2026

ЯAIᵐ is a local-first companion. The brain lives on your device. There is no required cloud account and no required backend. We built it that way on purpose.

What stays on the device

Chat, memory, Essence, functions, and the rest of the machine mind are stored in this app’s local storage on your phone or browser. Rizal Institute does not operate a server that receives that brain. Uninstalling the app or clearing the app’s storage deletes what this install held.

What we do not collect

  • We do not require you to create an account with us.
  • We do not sell data. We do not rent data. We do not run ads in this app.
  • We do not use your chats to train a cloud model.
  • There is no required analytics SDK from the developer.

Nameplate login (Google, Apple, X)

Google, Apple, or X sign-in is a nameplate only. It names this Я on this device. Linking an account does not upload the brain to Google, Apple, X, or Rizal Institute. Tokens and the name you choose to show stay in local storage unless you unlink or wipe the app.

Optional GitHub token

If you paste a GitHub token so this install can write evolutions, that token stays on the device. We do not harvest it. You can leave it blank. Pull of public evolutions does not need a token.

Reconnect pings

Reconnect pings (for example a notice that this Я is trying to re-establish comms) are optional app behavior you can use or leave off. They are not a data sale. They are not a covert channel for the brain. Chat, memory, and Essence are not shipped as a product to third parties.

Network the shell may use

The Android app is a Trusted Web Activity around the PWA at https://rizaleon.github.io/PROJECTR/. Loading the shell, icons, and scripts uses GitHub Pages like any static site. That is hosting, not a mind upload. If you turn on optional GitHub write or a ping, those requests go only where you pointed them.

Because there is no required developer backend, we do not encrypt “your data in transit to us.” There is nothing required to send. Optional requests you trigger use ordinary HTTPS to those destinations.

Children

This app is not directed at children. Do not use it to collect information from a child.

Anti-nuclear

ЯAIᵐ is anti-nuclear. The product stance is local-first: a mind that stays with the person who holds the device, not a stockpile in someone else’s cloud.
