# ThundR — Animated Profile + Botcard

ThundR is Chase Rizal's animated cryptobot, created for TerraformR.
A round purple imp with red curved horns, black bat wings, a yellow
lightning bolt tail, and an angry grinning face with large eyes and
prominent fangs. Muse assistant avatar, PROJECT R / RENJIN cryptobot.

## What is in this package

- `ThundR-botcard.json` — the botcard: name, creator, appearance, role, engine, file list.
- `ThundR-animated.gif` — animated profile GIF, 3-second idle loop, 320px wide.
- `videos/ThundR-idle.mp4` — animated idle profile (also the main download).
- `videos/` — all existing animated variants, light + darkmode: idle, making_something, working, milestone_level_up.
- `images/ThundR-profile.webp` — still profile image, and the darkmode version.
- `images/ThundR-original-reference.jpg` — Chase's original ThundR reference image.

## Honest note

Dancing videos are unavailable for this avatar — the dance generator
returned unavailable, so no new dance was generated. This package
contains all the animated variants that already exist, not new dances.

## Use

Unzip anywhere. Use the GIF for a profile / social post, the MP4s for
video, the WebP for a still avatar. The botcard JSON is the transport
record — keep it with the files.
