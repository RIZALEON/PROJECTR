- `index.html` — Working interactive terminal shell. Glowing electric green rounded border, starry CRT scanline backdrop, indigo purple RENJIN header, live `R:\>` prompt with a blinking green cursor. Commands: `help`, `status`, `rzl`, `version`, `clear`, plus custom input. Up / down recalls earlier commands.

## Use

Open `index.html` in a browser, or drop the folder straight into GitHub / RKLOWD.
Type at the `R:\>` prompt and hit Enter. It responds locally — no network, no external model, pure RZL.
