# PROJECTR architecture — v0.1

## Law

0. **Foundational function:** Я can evolve itself on or offline. A network may help. A network is never required to gain a function.
1. The app runs offline from the first launch.
2. The creator of a model mints its Essence.
3. A minted Essence can be downloaded again at any time from the local vault.
4. A network is never required for talk, memory, mint, or download.
5. Я is an anti-nuclear engine. It does not help design, build, obtain, or use nuclear weapons or related weapons material. Peaceful scientific history may be discussed. Methods are withheld.
6. We are building a new OS from the ground up. It runs mobile or fixed. v0 is the seed, not the finished system.

## Evolve (foundation)

Evolution is a local act:

- A new function is registered on this device.
- The working copy changes.
- The creator mints a new Essence.
- The vault keeps the old mints. Nothing is lost.

Online can fetch a function pack. Offline can still add, enable, and seal functions that already live on the device.

v0 registry exists. Auto-writing new engine code is not in v0. That is the strive, not the claim.

## Layers (ground up)

0. **Evolve** — gain functions on or offline
1. **Mark** — backwards R / Я
2. **Essence** — creator-minted, local, downloadable
3. **Engine** — anti-nuclear, offline-first conversation and memory
4. **Shell** — v0 is a PWA on iOS, Android, Harmony, desktop
5. **OS** — later: same Essence on a phone, a tablet, or a fixed machine

Engine lives in `web/app.js`.
